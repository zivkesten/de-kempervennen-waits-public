# De Kempervennen public park waits

Public, non-personal relay for the family trip companion. Contains only park and attraction names, open status, posted wait minutes, and source/fetch timestamps from the documented [Queue-Times API](https://queue-times.com/en-US/pages/api). No family, booking, itinerary, location, account, or private repository data.

Refreshed by GitHub Actions every five minutes on GitHub's free public-repository runners. Consumers must show timestamps and stale/error states; posted waits are estimates from the source, not guarantees.
